# Archivio

Materiale storico, conservato solo come riferimento. **Niente di ciò che è qui dentro va applicato di nuovo.**

- `patches/` — patch (tavoli, performance, takeaway, ingredienti, upload immagini) **già applicate** al codice in `apps/web` e `supabase/functions` tra dicembre 2025 e gennaio 2026.
- `sql/` — script SQL una-tantum **già eseguiti** sul database di produzione (unificazione categoria Toast, rinomina Toast → Panini). Le migrazioni ufficiali vivono in `supabase/migrations/`.
